# MMI Feature Section v2.0.0 (simple)

Only **one** shortcode. Tech news / hero / TagDiv options removed.

## Download

https://github.com/heenagupta198/Amazon-Api-Plugin/raw/cursor/feature-news-static-grid-3fd9/mmi-feature-news-v2.0.0.zip

## Install

1. Upload zip on **/devices/** → Activate (resets settings to Feature defaults).
2. **Elementor:** keep **one** Shortcode widget with `[mmi_feature_news]` only.
3. **Delete** any other shortcode widgets (`mmi_feature_hero`, tech news, duplicate Feature blocks) — they cause blank spacing.
4. Clear WP Rocket cache.

## Defaults

- Title: **Feature**
- Posts: English site **Feature** category (ID **9**)
- View All: https://www.mymobileindia.com/feature/
- Desktop **4** cards, mobile **1** card, no slider
