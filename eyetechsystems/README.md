# Eye Tech Systems — Website

Modern React website for **eyetechsystems.com** (Vite + React).

## Run locally

```bash
cd eyetechsystems
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Upload the `dist/` folder to your hosting (cPanel, Netlify, Vercel, etc.) and point **eyetechsystems.com** to it.

## Contact form

## Customize

- Services: `src/data/services.js`
- Colors and layout: `src/App.css`, `src/index.css`
