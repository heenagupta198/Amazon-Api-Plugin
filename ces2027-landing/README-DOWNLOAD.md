# CES 2027 Leroux page template — direct download

Use these links in the browser (right‑click → **Save link as…** if tap does not download).

## ZIP (recommended)

- **GitHub raw (ZIP):**  
  https://github.com/heenagupta198/Amazon-Api-Plugin/raw/main/ces2027-landing/ces2027-leroux-template.zip

Unzip and upload `ces2027-leroux-template.php` to your WordPress theme folder, then assign the page template **CES 2027 Landing Page**.

## Local download page

Open `download.html` in this folder in your browser for one-click download buttons (works when this folder is on your computer or hosted on a web server).

## WordPress

1. Upload `ces2027-leroux-template.php` to `wp-content/themes/leroux/` (or your child theme).
2. Edit the CES 2027 page → Template → **CES 2027 Landing Page** → Update.
