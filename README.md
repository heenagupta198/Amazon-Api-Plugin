# Amazon-Api-Plugin

## MMI Linked Device Articles (`mmi-linked-device-articles/`)

Separate from **MMI Content Slider**. Related news articles on Devices product pages.

Download: `mmi-linked-device-articles-v1.1.0.zip`

Install the same zip on **both** WordPress installs (English news + `/devices/`). Do not replace MMI Content Slider on Devices. On the English news site, deactivate MMI Content Slider if both are active — it can erase linked products on Update.

See `mmi-linked-device-articles/readme.txt`.
